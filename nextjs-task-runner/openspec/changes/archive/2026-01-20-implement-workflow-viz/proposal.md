# Proposal: Implement Workflow Visualization and Sidebar

## Summary
Add a sidebar navigation with "Home" and "Workflow" links. The "Workflow" page will feature a dashboard to visualize dynamic workflows using `@calmo/task-runner` and Mermaid diagrams.

## Motivation
To provide a visual interface for the task runner capabilities and demonstrate the dynamic workflow execution steps.

## Proposed Changes
1.  **Sidebar**: Introduce a collapsible sidebar using `shadcn/ui` components (or similar/custom simple sidebar if shadcn is overkill, but sticking to project request).
2.  **Workflow Page**: A new route `/workflow` that runs the demo workflow and renders the mermaid graph.
3.  **Visualization**: Render the mermaid graph generated by the task runner.

## Verification Plan
-   **Manual**: Navigate to `/workflow` and verify the graph appears and represents the hardcoded tasks.
-   **Automated**: Ensure the page builds and renders without errors.
